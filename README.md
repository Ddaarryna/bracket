Перевірка правильних пар дужок.
Ця програма на C++ зчитує рядок з дужками (наприклад, {[]}[()]) та виводить правильно складені пари дужок у порядку їх появи. Програма обробляє неправильні або зміщені дужки та коректно їх парує.

Особливості:
Підтримка різних типів дужок: (), [], {}.

Виводить тільки правильні пари дужок у правильному порядку.

Ігнорує неправильні або невідповідні дужки.

Приклад:
Вхід: {[]}([)]
Вихід: {}[]()[]
